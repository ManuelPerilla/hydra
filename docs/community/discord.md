# Discord de colaboradores

Estado: estrategia lista, servidor aún no creado. Antes de abrirlo, registrar moderadores y contacto privado real en MAINTAINERS.md y CODE_OF_CONDUCT.md.

Canales: bienvenida y normas, anuncios solo mantenedores, primeros pasos, arquitectura, contribuciones, experimentos y ayuda. Roles: miembro, colaborador, moderador y mantenedor. Moderación con permisos mínimos, canal privado para reportes y revisión por una persona no involucrada en apelaciones.

GitHub conserva decisiones, errores y ADR. Discord facilita acompañamiento; toda decisión técnica se resume y enlaza en GitHub. No publicar kubeconfigs, tokens, IPs internas ni capturas con datos de usuarios.

Onboarding: el miembro acepta normas, elige idioma y área, levanta el laboratorio local y recibe una primera issue real. Una sesión mensual voluntaria enseña dry-run y recuperación. Compartir grabaciones solo con consentimiento. Sin bots ni suscripciones de pago obligatorios.
