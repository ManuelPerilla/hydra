# Changelog

## 0.1.0 en desarrollo

- API REST, OAuth GitHub y SignalR con persistencia PostgreSQL.
- Agente Rust con ámbito de namespace, precondición UID y recuperación observada.
- Interfaz Next.js en cuatro idiomas, con RTL y estados reales.
- Dirección visual Tarde de Té y Lino: bastidor de pods, costuras, botón acolchado y bitácora sobre papel, con fuentes locales y movimiento reducido.
- k3s local mediante Docker, Terraform Oracle ARM/Cloudflare y CI por arquitectura.
- Gobernanza, plantillas y documentación FinOps.

La publicación remota y validación de producción se registrarán cuando se ejecuten.
